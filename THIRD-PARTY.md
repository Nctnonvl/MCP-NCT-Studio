# Thành phần bên thứ ba

Giấy phép MIT trong `LICENSE` áp dụng cho mã nguồn dự án NCT Studio.
Thư viện và tài sản bên thứ ba giữ giấy phép riêng:

- Inter và Instrument Serif: SIL Open Font License; bản giấy phép nằm trong `source/assets/*-OFL.txt`.
- Python: giấy phép Python Software Foundation. Bản đóng gói giữ giấy phép ở thư mục runtime.
- Windows MCP, MCP Python SDK, pyperclip và các thư viện phụ thuộc: xem metadata/giấy phép của từng gói được khóa trong `source/uv.lock`.
- Microsoft WebView2 SDK/Runtime: điều khoản của Microsoft. SDK được tải từ NuGet chính thức trong bước chuẩn bị build; bản đóng gói giữ LICENSE và NOTICE của SDK.
- Inno Setup: công cụ biên dịch bộ cài, không phải mã nguồn thuộc dự án. Script chuẩn bị build dùng bản 6.4.3 từ phát hành chính thức.

Không đưa cookie, tài khoản đăng nhập Facebook, API key, token Telegram hoặc khóa ký cập nhật riêng vào repository.
